# Reading Tracker

一个 Obsidian 插件：精准统计文件夹 / 笔记的浏览次数与最近浏览时间，帮助你掌握学习进度、安排复习。

> 适合用它维护"知识体系库"：哪些模块学得多、哪些放久了该复习，一眼可见。

## 功能

### 📊 阅读统计
- **模块 / 文件** 两种统计模式：按文件夹层级聚合，或精确到单个笔记
- 记录每个文件 / 模块的**浏览次数**和**最近浏览时间**（相对时间自动刷新）
- 可自定义模块聚合层级（按第几级文件夹统计）
- 支持**忽略文件夹**、显示 / 隐藏从未打开过的笔记
- 排序方式：浏览次数 / 最近浏览 / 名称 / 复习等级

### 🎨 复习等级标记
- 内置 4 个颜色等级：紧急复习 🔴 / 重点掌握 🟠 / 定期回顾 🔵 / 已掌握 🟢，可自定义名称与颜色
- 在列表中点击色点、右键笔记，或用命令面板为当前文件标记等级
- 支持按等级筛选统计列表

### 📌 学习节点
- 为任意笔记添加学习节点（备注），记录学习过程中的关键结论
- 面板中点击徽章即可查看 / 管理，复习完成时也可自动记录

### 🎯 每日复习目标
- 每天从库里随机抽取 N 个笔记作为当日复习任务，带进度条打卡
- 抽取策略可调：优先**等级靠前**的、优先**更久未浏览**的、仅从已标记等级中抽取
- 一键"换一批"，完成后自动记录学习节点

### 🔍 其他
- 日期筛选：全部 / 今日 / 昨日 / 自定义日期
- 打开面板时可自动进入"每日复习"页签

## 安装

### 手动安装
1. 下载 `main.js`、`styles.css`、`manifest.json` 三个文件
2. 放到你的仓库 `.obsidian/plugins/module-reading-tracker/` 目录下
3. 在 Obsidian 设置 → 第三方插件中启用 **Reading Tracker**

### 通过 BRAT 安装
1. 安装并启用 [BRAT](https://github.com/TfTHacker/obsidian42-brat)
2. 命令面板执行 `BRAT: Add a beta plugin for testing`
3. 输入本仓库地址，确认即可

## 使用

- 点击左侧边栏的 📊 图标，或命令面板执行 **打开 Reading Tracker**
- 打开某个笔记即为一次"浏览"，次数与时间自动累计
- 建议配合命令：**标记当前文件的复习等级**、**为当前文件添加学习节点**、**打开每日复习目标**

## 说明

- 所有统计数据仅保存在本地（插件目录下的 `data.json`），不会上传到任何服务器
- 插件 id 为 `module-reading-tracker`
